# Cómo cargar productos en la web de DIPA

Entrá a **tu-sitio/admin** e iniciá sesión con GitHub.

## Agregar un producto

1. Tocá **Productos → Nuevo producto**.
2. Completá **Nombre** y elegí la **Categoría**.
3. Escribí una **Descripción corta** (una o dos líneas).
4. Subí una **Foto principal**. Si todavía no tenés foto, dejala vacía: se muestra un recuadro con el texto que pongas en "Texto del recuadro sin foto".
5. Tocá **Guardar**. En un minuto aparece en la web.

## Cambiar o sacar un producto

- Para cambiarlo: abrilo, editá y guardá.
- Para sacarlo un tiempo: activá **Ocultar del sitio**. Así no lo perdés.
- Para borrarlo del todo: abrilo y tocá **Borrar**.

## Destacar un producto

Activá **Destacado**: la tarjeta sale con borde durazno y la etiqueta "Destacado".

## Producto con página propia

Si querés que un producto tenga su propia página (como "Stickers con logo"), activá **Tiene página propia** y completá la descripción larga, las opciones (forma, tamaños, material…) y la galería de fotos.

## Mensaje de WhatsApp

Cada botón "Consultá" abre WhatsApp con el mensaje "Hola DIPA! Quiero consultar por …" y el nombre del producto. Si querés otra frase, escribila en **Cómo se nombra en el mensaje de WhatsApp**.

## Datos del local

En **Datos del local** cambiás el WhatsApp, el Instagram, el horario y la dirección de toda la web de una vez.

## Fotos

Subí fotos livianas (menos de 1 MB). Una foto mandada por WhatsApp ya viene achicada y sirve.

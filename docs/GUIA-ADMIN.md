# Cómo cargar productos en la web de DIPA

Entrá a **tu-sitio/admin** y tocá **Iniciar sesión con Google** con tu cuenta. Solo pueden entrar los emails autorizados.

Todo lo que cambies queda en borrador hasta que tocás **Guardar y publicar** (abajo). Después de guardar, la web se actualiza en 1 o 2 minutos.

## Agregar un producto

1. En **Productos**, elegí la categoría en "Mostrar" (así el producto nuevo queda ahí).
2. Tocá **+ Nuevo producto** y escribí el nombre.
3. Completá la **Descripción corta** (una o dos líneas).
4. Tocá **Subir foto**. Si todavía no tenés foto, dejala vacía: se muestra un recuadro con el texto de "Texto del recuadro sin foto".
5. Tocá **Listo** y después **Guardar y publicar**.

## Cambiar el orden

Usá las flechas **↑ ↓** al lado de cada producto o categoría.

## Sacar un producto

- Un tiempo: abrilo y marcá **Ocultar del sitio**. No se pierde.
- Del todo: abrilo y tocá **Borrar producto**.

## Destacar un producto

Marcá **Destacado**: la tarjeta sale con borde durazno y la etiqueta "Destacado".

## Producto con página propia

Marcá **Tiene página propia** y completá la descripción larga, las opciones (forma, tamaños, material…), la galería de fotos y "También te puede interesar".

## Mensaje de WhatsApp

Cada "Consultá" abre WhatsApp con "Hola DIPA! Quiero consultar por …" y el nombre del producto. Si querés otra frase, escribila en **Cómo se nombra en el mensaje de WhatsApp**.

## Datos del local

En **Datos del local** cambiás el WhatsApp, el Instagram, el horario y la dirección de toda la web de una vez.

## Si algo sale mal

- **"Tu sesión venció"**: volvé a iniciar sesión. Lo que no guardaste sigue ahí.
- **"El catálogo se cambió desde otro lado"**: alguien más guardó mientras editabas. Recargá la página y hacé el cambio de nuevo.
- **"No se guardó: …"**: el mensaje dice qué falta corregir.
